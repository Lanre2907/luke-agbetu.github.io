Re-architecting a core marketing data load

Fisher Investments · 2026

Problem

History lived on-premises, and every daily run reprocessed the full dataset.

What I did

Authored the logical design, moved all-time history to an Azure source, and rebuilt the ADF pipeline as a rolling refresh.

Outcome

Daily runs scoped to a 2-year window, with no on-prem reloads and no redundant staging.
